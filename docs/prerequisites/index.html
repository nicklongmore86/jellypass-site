Prerequisites

What JellyPass needs
You needDetails
Jellyfin 12.x or 10.11.xJellyPass supports the current Jellyfin release and the one before it, and tests both against a real Jellyfin before each release (today 12.4.0 and 10.11.11). On any other version, household addresses answer 503 until an administrator confirms that exact version; see Jellyfin versions.
A Jellyfin administrator accountThe setup wizard signs in once with an administrator's name and password, creates an API key of its own, and doesn't store the password. Only administrators can change item tags and user policies. Configuring by environment variables instead? Create the key yourself under Dashboard → API Keys.
SeerrSeerr, or Jellyseerr, with its own setup finished and users imported from or linked to Jellyfin; it sends JellyPass the webhook. Overseerr on its own supports only Plex and does not work. Giving JellyPass Seerr's API key as well is needed for the setup wizard's webhook step, the apps, the request backfill and 4K requests.
Docker with Compose 2.24 or newerThe recommended install; the Compose file treats .env as optional, which needs 2.24. Images are published for linux/amd64 and linux/arm64. You can also run it from source with Node.js 22 or later and pnpm.
A reverse proxy with HTTPSFor household addresses: a domain you control, a DNS record for each household name, and a certificate covering each one. No wildcard is needed, and the names can be anything. See Reverse proxy.
A TMDB API keyOnly for the household apps, which read titles, posters and details from TMDB. A v3 API key or a v4 read access token from your TMDB account's API settings. Read TMDB's API terms.
Somewhere private for the data folderThe state file, grants.json, holds everything JellyPass decides, including Jellyfin user IDs and media names. A wizard install also keeps settings.json and admin-token there, which hold your keys and tokens. Keep the folder private and back it up.

Network

  • JellyPass must reach Jellyfin and Seerr. Inside Docker, localhost is the JellyPass container itself: use a shared Docker network and service names (http://jellyfin:8096), or the host's own LAN address, in place of the example http://192.0.2.20:8096.
  • Seerr must reach JellyPass's webhook on the admin listener, for example http://jellypass:8788/webhooks/seerr.
  • Members reach household addresses through your reverse proxy, which routes them to port 8787.
  • Administrators reach the admin site on port 8788, which must not be public (see Security).
  • Members must not be able to reach Jellyfin or Seerr directly: household privacy holds only on household addresses.
