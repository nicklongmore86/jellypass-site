Settings reference

JellyPass reads its settings when it starts, from environment variables (with Compose, put them in .env) and from what the setup wizard stored in settings.json. A variable in the environment always wins, and the wizard shows that setting as locked. "Required" means required from either source: without JELLYFIN_URL, JELLYFIN_API_KEY and WEBHOOK_TOKEN, JellyPass starts in setup mode instead of stopping.

An invalid value stops startup with a message naming the setting, except LOG_LEVEL: an unrecognised level logs a warning and JellyPass uses info. Booleans take true, false, 1 or 0.

Connections and basics

SettingRequiredDefaultWhat it does
JELLYFIN_URLYes—Jellyfin's base URL as JellyPass reaches it, such as http://jellyfin:8096.
JELLYFIN_API_KEYYes—A Jellyfin administrator API key. The setup wizard creates one for you.
WEBHOOK_TOKENYes—Secret Seerr's webhook must send. Use a long random value. The setup wizard generates one.
ADMIN_TOKENRecommendedthe setup token in admin-token, else WEBHOOK_TOKENBearer token for the admin API, /metrics and the setup wizard. Use a value different from WEBHOOK_TOKEN.
SEERR_URLSet together—Seerr's base URL as JellyPass reaches it, such as http://seerr:5055.
SEERR_API_KEYSet together—Seerr API key. Startup stops if only one of the two is set.
STATE_FILENo./data/grants.jsonThe state file. The Compose file sets /app/data/grants.json.
SETTINGS_FILENosettings.json next to STATE_FILEWhere the setup wizard stores its settings (mode 0600; it holds keys and the webhook token). admin-token is kept in the same folder. Never created on an install the wizard hasn't been used on.
ADMIN_HOSTNo127.0.0.1; 0.0.0.0 in the imageAdmin listener address. Compose publishes it on 127.0.0.1 only. Keep it private.
ADMIN_PORTNo8788Admin listener port: the admin site and API, /metrics, /webhooks/seerr and /health. Must differ from PORT while the household gateway is on.
HOSTNo0.0.0.0Member listener address.
PORTNo8787Member listener port: household addresses only. It starts only with the household gateway on.
RECONCILE_INTERVAL_SECONDSNo300How often tags and policies are re-applied and retried. 0 disables; at most 86400.
CATALOG_SYNC_INTERVAL_SECONDSNo3600How often the Library catalogue is refreshed from Jellyfin. 0 disables; at most 604800.

Household addresses and apps

SettingRequiredDefaultWhat it does
HOUSEHOLD_GATEWAY_ENABLEDNotrue with HOUSEHOLD_DOMAIN, otherwise falseStarts the member listener, which serves each household at the addresses you map to it. Needs TRUSTED_PROXIES.
HOUSEHOLD_APP_ENABLEDNofalseServes the household web app at /jellypass/app/ and its API, used by every JellyPass app. Needs the household gateway, Seerr and TMDB_API_KEY. While on, at most 100 households.
TMDB_API_KEYWith the app—TMDB v3 API key (32 hexadecimal characters) or v4 read access token. Checked at startup, never logged. Use a key for JellyPass alone.
TV_ADDON_ENABLEDNofalseThe global gate for the experimental TV add-on. Each household's TV switch then decides who gets it. Needs HOUSEHOLD_APP_ENABLED.
HOUSEHOLD_PLUGIN_ROUTESNo—Exact lowercase plugin paths, separated by commas, added to the household allow-list. No wildcards. Plugin routes can reveal other households' data: audit each one before adding it.
WS_IDLE_TIMEOUT_MSNo300000Closes a household WebSocket after this long with no traffic either way. 0 disables.
WS_UPSTREAM_IDLE_TIMEOUT_MSNo180000Closes a household WebSocket after this long with nothing from Jellyfin. 0 disables.

Which addresses a household has, and whether it has app and TV access, are not settings: you set them per household in the admin site. See Household addresses and App and TV switches.

Backfill, proxies and the rest

SettingRequiredDefaultWhat it does
TRUSTED_PROXIESWith the gatewayemptyReverse proxies whose X-Forwarded-For is believed: IPv4/IPv6 addresses and CIDR ranges separated by commas, no ports. Startup stops without it while the household gateway is on. See Reverse proxy.
REQUEST_BACKFILL_SINCENo—Turns on the request backfill for requests created on or after this date: YYYY-MM-DD (UTC midnight) or an ISO 8601 date-time with Z or an offset.
REQUEST_BACKFILL_ENABLEDNotrue when the date is setSet false to pause the backfill. Needs Seerr and the date.
JELLYFIN_UNTESTED_VERSION_OKNo—One exact Jellyfin version outside the supported releases, such as 13.0.0, that counts as confirmed, so household addresses serve on it. See Jellyfin versions.
JELLYFIN_PUBLIC_URLSNo—Jellyfin's public URLs, separated by commas, for the self-check's direct-access probes.
SEERR_PUBLIC_URLNo—Seerr's public URL, for the self-check. Seerr should be reachable by administrators only.
LOG_LEVELNoinfodebug, info, warn or error. Only debug changes output today (routine disconnects and skipped backfill items).
JELLYPASS_IMAGECompose only…/jellypass:latestThe image the Compose file runs. Pin a version.
JELLYPASS_ENV_FILECompose only.envAnother settings file for the Compose file.

Deprecated and legacy settings

These keep working for existing installs. Don't use them on a new one.

SettingRequiredDefaultWhat it does
TV_ADDON_HOUSEHOLDSDeprecated—Household IDs separated by commas, or * for all, including ones created later. While set with TV_ADDON_ENABLED=true it decides TV access at every start and locks the admin site's TV switches. Remove it and restart to manage TV access with the switches, which keep what it last selected.
HOUSEHOLD_DOMAINLegacy—For installs from before 4.0.0: gives every household the extra address https://<prefix><household>.<domain> and turns the gateway on. Leave it empty on a new install.
HOUSEHOLD_HOST_PREFIXLegacyjelly-The prefix of those addresses, only with HOUSEHOLD_DOMAIN. 1 to 32 lowercase letters, digits and hyphens.
LEGACY_WEBHOOK_ON_MEMBER_PORTUpgrade aidfalseAlso answers POST /webhooks/seerr on the member listener for a host that is no household's, so a 3.x webhook URL keeps working while you change it. Logs a warning at startup. Turn it off afterwards.

A minimal .env

With the setup wizard, all you need is the pinned image. Without the wizard, for household addresses and the apps, use the example below after replacing every placeholder with your own value and 192.0.2.10, a documentation address, with your proxy's. JellyPass checks some values at startup: a literal TMDB_API_KEY=tmdb-key, for one, stops it.

JELLYPASS_IMAGE=ghcr.io/nicklongmore86/jellypass:X.Y.Z
JELLYFIN_URL=http://jellyfin:8096
JELLYFIN_API_KEY=jellyfin-admin-api-key
SEERR_URL=http://seerr:5055
SEERR_API_KEY=seerr-api-key
WEBHOOK_TOKEN=long-random-secret
ADMIN_TOKEN=different-long-random-secret

# Household addresses and the apps
HOUSEHOLD_GATEWAY_ENABLED=true
HOUSEHOLD_APP_ENABLED=true
TMDB_API_KEY=tmdb-key
TRUSTED_PROXIES=192.0.2.10

The example settings file, .env.example, lists the main settings with comments. The server reference has every setting in full detail, with the administrator API and metrics.
